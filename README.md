# gridlock-808
A high-energy, multiplayer cyberpunk hacking race built from scratch for the Game Boy Advance.gridlock-808 is a fast-paced, grid-based competitive arcade game developed for the GBA Jam 2026 to mark the console's 25th anniversary. Players connect via the GBA Game Link Cable (Multi-Pak mode) to battle head-to-head in a neon terminal arena,.
